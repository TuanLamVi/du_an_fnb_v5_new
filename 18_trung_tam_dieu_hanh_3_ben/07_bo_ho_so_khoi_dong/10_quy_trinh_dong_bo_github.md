# QUY TRÌNH ĐỒNG BỘ GITHUB (GITHUB SYNC PROCESS) F&B SMART V5.1

1. Cập nhật hồ sơ/tài liệu trên máy tại `ho so du an fnb`.
2. Kiểm tra thay đổi git local (`git status`).
3. Commit với thông điệp chuẩn (`docs: ...`).
4. Push lên `origin main` tại `https://github.com/TuanLamVi/du_an_fnb_v5_new`.
5. ChatGPT và PO kiểm tra trạng thái đồng bộ trên GitHub.
